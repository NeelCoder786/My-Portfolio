# Neel Sharma - Portfolio

A cinematic personal portfolio built with Next.js, React, GSAP, Three.js, Supabase, and Tailwind CSS.

## Features

- Scroll-driven video backgrounds
- Responsive portfolio sections
- Admin dashboard for projects and images
- Supabase-backed content and analytics
- Contact and resume management

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
